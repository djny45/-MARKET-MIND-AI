# Historical scenario review

## Purpose
Evaluate already-completed historical scenarios as descriptive research. This is not an exit planner.

## Procedure
1. Define the historical sample and selection rules before reviewing outcomes.
2. Record the observations and timestamps used in each scenario.
3. Report distributions and uncertainty, not a single guaranteed outcome.
4. Check for look-ahead bias, survivorship bias, overlapping samples, and data leakage.
5. Preserve failed and inconclusive cases in the report.

## Boundaries
Do not advise when to exit, close, sell, or reduce an investment. Do not create stop-loss or take-profit instructions, orders, or portfolio actions.
