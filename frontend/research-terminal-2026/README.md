# MARKET-MIND AI Research Terminal 2026

A standalone, responsive HTML dashboard preview for the offline research workflow.

## Open the dashboard

Open `frontend/research-terminal-2026/index.html` directly in a modern browser. No npm install, server, API key, or network connection is required.

## UI sections

- **Overview:** synthetic chart, dataset cards, sample watchlist, feature coverage, and terminal activity.
- **Dataset Lab:** browser-local CSV picker for a small preview (up to 10 MB, first 12 columns and five data rows), plus commands to inspect files with the Python tools.
- **Indicator Matrix:** definitions and limitations for historical annotations.
- **Terminal Logs:** simulated read-only log console with a small allowlist of UI commands (`help`, `status`, `dataset`, `indicators`, `clear`).

## Important limitations

- Dashboard chart and sample instrument values are fabricated UI demo data. They are not real-time market data.
- The terminal accepts only its documented UI commands; it does not execute shell commands.
- The CSV picker reads only the file you explicitly select, in browser memory using FileReader; it does not upload or transmit it. The quick preview is intentionally basic (CSV quoting support, non-empty line count, limited rows/columns), not a replacement for robust OHLCV validation. Run the Python research utilities separately from the repository root for full validation and indicator analysis.
- No exchange/broker connections, forecasts, trade signals, or order execution are included.
- SMC swing annotations may use future bars and can introduce look-ahead bias.

## Import a Python quality report

The Dataset Lab can display the JSON report generated by the existing offline validator:

```bash
python backend/examples/offline_dataset_report.py path/to/data.csv --timestamp-column timestamp --output report.json
```

Then, in the dashboard's **Python Report Viewer**, choose the generated `report.json` file. The browser reads the JSON locally and displays row count, column names, quality checks, numeric summaries, and optional UTC range. It does not upload the report or run Python in the browser.

If your CSV has no timestamp column, omit `--timestamp-column timestamp`. Run the command from the repository root in an environment with the project's Python dependencies installed.

## Historical indicator annotations

The dashboard can display an optional TA-Lib indicator report generated from a local OHLCV CSV:

```bash
python backend/examples/offline_indicator_report.py path/to/data.csv --ta-lib --output indicators.json
```

Add `--timestamp-column timestamp` when your dataset has a timestamp column and you want it included in the report. The optional TA-Lib dependencies must be installed from `backend/requirements-ta-lib-research.txt`.

Open **Dataset Lab → Historical Indicator Viewer** and select `indicators.json`. The viewer summarizes valid/null counts and latest valid historical values for RSI, MACD, ATR, SMA/EMA, and Bollinger Bands. Select an indicator to plot its historical series; null values create gaps, and the horizontal axis is row index (not timestamps). It imports the report locally and does not run calculations or upload files in the browser.

This report is for retrospective research only. Warm-up values may be null; values are not forecasts, trade signals, or recommendations. The exporter currently supports TA-Lib indicators; SMC annotations remain available through the existing research pipeline and are not included in this JSON exporter.


## Run the offline report exporter tests

From the repository root:

```bash
PYTHONPATH=backend python -m unittest backend.tests.test_offline_indicator_report
```

The tests use a mocked pipeline to verify JSON-safe null handling, valid/null counts, timestamp inclusion, and empty-report behavior without requiring TA-Lib or market data.
